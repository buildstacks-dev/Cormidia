# Scheduled learning distillation

The brief contains only evidence clusters that deterministic prechecks found
actionable, unsuppressed, and not duplicated by pending candidates or the live
bundle. Produce structured candidate proposals; do not inspect or mutate files.

For each cluster worth carrying forward:

1. Choose the lowest-authority useful destination: `okf_concept`,
   `skill_draft`, `protocol_proposal`, `eval_or_gate_proposal`, `ticket`, or
   `reject`.
2. Keep scope narrow. Permissions, security posture, deployment, tools, gates,
   and constitutional behavior never belong in OKF.
3. Use `skill_draft` for a recurring, repeatable procedure with steps, tools,
   pitfalls, and examples—the governed successor to retro keyword curation.
4. Set `topic_key` exactly to the cluster's `error_class`.
5. Claim efficacy only when the candidate asserts a measurable improvement;
   that claim will require a declared experiment before publication.

Return only the native structured-output object. Agents do not write active
bundles, manifests, policy, evals, reviews, rejections, or proposal files.
