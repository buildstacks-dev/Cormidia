# Research records

Narrative decision records in this directory use the current Cormidia name and
paths. Raw campaign and live-observability evidence is different: signed,
content-addressed, or hash-referenced artifacts must remain byte-for-byte as
captured so their provenance continues to verify.

The immutable evidence boundary is limited to:

- `evals/campaigns/**`
- `2026-07-12_live-ui/buildstacks-telemetry.evidence/**`
- `2026-07-12_live-ui/buildstacks-telemetry.html`
- `2026-07-12_live-ui/buildstacks-final-snapshot.json`

Do not normalize product identifiers, paths, prompts, or repository names
inside those artifacts. Explain them as historical evidence instead of editing
their bytes.
