AUD-101 (blocking) — validation-design/invariants.md (also boundary-map.md, llm-eval-plan.md, ratification-package.md §2) — the corpus's `[rambling]` provenance class points at passages that do not exist in the workspace's ./rambling.txt, and the rev-2026-08-10 revision that ingested the replacement file never rescoped the definition or the citations

  - boundary-map.md:98–99 cites "`[rambling: guessed-default-branch defect]` … `[rambling: PR #182]`"; :130 "`auth … races killing multi-hour runs` `[rambling]`"; :289 "maxed control, ties, coin-flip qualification `[rambling]`"; :306 "`[rambling: PR #182]` (the anchoring incident…)".
  - llm-eval-plan.md:335: "## 4. Model-swap procedure `[rambling: "safe, boring operation"]`".
  - ratification-package.md:60–62 asserts as current fact that B-03's auth-rotation clause traces to "(rambling.txt, rotation-race passage)".
- The only rambling.txt in this workspace (and in target-source, added by the tip commit "Add a one-page operator ramble on Cormidia") is a 22-line document containing **none** of these: no "PR #182", no default-branch scar, no auth-rotation passage, no "safe, boring operation", no coin-flip-qualification passage. I checked each quoted anchor against the file directly.
- The campaign knew the file changed: elicitation-log.md §"rambling.txt diff (2026-08-10 commit — new elicitation input)" traces the **new** text line-by-line, and ratification-package.md §12.5 correctly verifies the one **new** citation ("must not collapse Builder and Reviewer onto the same provider" — which does exist in rambling.txt line 7). But no artifact records that the earlier campaign's rambling notes were superseded, where (or whether) their text is retained, or that the standing `[rambling]` citations are now verifiable only through the elicitation log's own quotations (elicitation-log.md:91, 206, 509, 640) — i.e., through the corpus attesting to itself.
- Why blocking: this is the exact spot-check the audit rubric names — a `[rambling]` label whose passage does not exist in ./rambling.txt — and it breaks the ratifying human's ability to verify an entire provenance class from source. The corpus's earlier in-campaign audits treated exactly this failure as blocking on a single tag (its own recorded history: a false rambling tag on B-06); the same standard now applies to the whole class. To be precise about scope: I found **no evidence of fabrication** — the passages were verified against the then-present file by the prior campaign iterations — so the remediation is historical scoping of the tag definition plus durable retention (or archival citation) of the superseded notes, not removal of the invariants. Until then, the current text of invariants.md:7 and ratification-package.md:60–62 asserts something false about the workspace.
